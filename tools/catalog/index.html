Profils EEP pris en charge

Ces profils sont décodés en mode générique. Les tests matériels restent nécessaires pour confirmer les fonctions du modèle utilisé.

Votre produit n'est pas dans la liste ?

Remplissez le formulaire (marque, référence, profil EEP, procédure d'appairage, photo). Après validation, la fiche est créée et le produit apparaît dans Ocean2MQTT à la version suivante. Un compte GitHub gratuit est nécessaire.
