# Security policy / Politique de sécurité

[English](#english) · [Français](#français)

## English

Report Ocean2MQTT vulnerabilities privately. Use **Report a vulnerability** on the [GitHub security advisories page](https://github.com/eHomeLabs/Ocean2MQTT/security/advisories) if the button is available. Otherwise, email [dev@ehomelabs.fr](mailto:dev@ehomelabs.fr) with the subject `[Ocean2MQTT Security]`.

Include the affected version or image tag, installation method, observed impact and steps to reproduce. Remove passwords, MQTT tokens and Remote Commissioning codes from configuration snippets and logs.

Keep vulnerability details private while a fix is being coordinated. For ordinary bugs without security impact, use [GitHub Issues](https://github.com/eHomeLabs/Ocean2MQTT/issues).

## Français

Signalez les vulnérabilités d’Ocean2MQTT en privé. Sur la [page des avis de sécurité GitHub](https://github.com/eHomeLabs/Ocean2MQTT/security/advisories), utilisez **Report a vulnerability** si le bouton est disponible. Sinon, écrivez à [dev@ehomelabs.fr](mailto:dev@ehomelabs.fr) avec l’objet `[Ocean2MQTT Security]`.

Indiquez la version concernée (ou le tag de l’image), le mode d’installation, l’impact observé et les étapes permettant de reproduire le problème. Retirez les mots de passe, jetons MQTT et codes Remote Commissioning des extraits de configuration et des journaux.

Gardez les détails de la vulnérabilité privés pendant la coordination du correctif. Pour un bug fonctionnel sans enjeu de sécurité, utilisez les [Issues GitHub](https://github.com/eHomeLabs/Ocean2MQTT/issues).
